🛡️ Cryptographic Security Overview

STANDARDS & PARAMETERS

Explore the algorithms, key sizes, and design principles that protect your data within the application.

🔐

Symmetric File Encryption

AES-256-GCM

Files are encrypted using Advanced Encryption Standard (AES) in Galois/Counter Mode (GCM) with a 256-bit key. AES-GCM provides both confidentiality and authenticated integrity check in a single pass.

  • Key size: 256 bits
  • IV size: 96 bits (randomly generated)
  • Authentication tag: 128 bits (GCM Tag)
🗝️

Asymmetric Key Protection

RSA-2048-OAEP

The AES session key is securely protected by wrapping it with RSA-2048 asymmetric encryption. Optimal Asymmetric Encryption Padding (OAEP) with SHA-256 prevents chosen-ciphertext attacks.

  • Key size: 2048 bits
  • Padding: PKCS#1 OAEP
  • Hashing function: SHA-256
🔑

Key Derivation Engine

PBKDF2-SHA256

Passphrases are transformed into secure cryptographic keys using Password-Based Key Derivation Function 2 (PBKDF2). This mitigates offline brute-force attacks by increasing computational cost.

  • Iterations: 310,000
  • Salt length: 128 bits (16 bytes)
  • Internal Hash: SHA-256
✍️

Digital Signature Authenticity

RSA-SHA256

Provides non-repudiation and sender authenticity. If signature generation is selected, the hash of the ciphertext is signed using the sender's ephemeral RSA private key.

  • Verification key: RSA Public Key (embedded)
  • Signature format: Hex string
  • Standard: PKCS#1 v1.5
🔍

Data Integrity Validation

SHA-256

Protects the package ciphertext from silent data corruption or intentional tampering. The hash is compared dynamically during decryption; any modification stops the process immediately.

  • Hash length: 256 bits (32 bytes)
  • Output: 64 hexadecimal characters
  • Collision-resistant design
🛡️

Zero Storage & Privacy

Stateless Architecture

The system retains absolutely no persistent record of files, decryption passwords, or keypairs on disk. The operation is in-memory only and immediately garbage-collected once streamed.

  • Session state: None
  • File retention period: 0 seconds
  • No tracking database
🛡️

Zero-Trust Encryption

Your files are only as secure as your password. Because the application does not store your passphrase, it is impossible for administrators, hosting providers, or adversaries to decrypt your files without access to your passphrase. Always share passphrases through an out-of-band, secure communication channel (such as an encrypted messaging app).
